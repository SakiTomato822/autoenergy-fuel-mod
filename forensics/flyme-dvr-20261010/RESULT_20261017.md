# 原厂DVR本地调查续报（2026-10-17）

尚未实现原厂DVR画面、录像或回放，也没有足够证据认定本车独立DVR在线或缺失。此前交接中的只读结果继续有效；本轮没有车辆写入、控制帧、刷写、服务停止或主动探测。

本轮先确认CP middleware是否存在遗漏的DVR消费者。对已经取得的14个CP B槽middleware做定向交叉引用：`MMI_DVR_Command`、`DVR_SystemSts`和`DVRConfig`的命中都位于生成式服务/事件名称表、`InstanceIdentifier`/`vector<string>`追加和固定服务ID写入路径。没有发现具体`GetNewSamples`、`SetReceiveHandler`或`HandleEventMMI_DVR_Command`实现或独立引用。

`Samples`中的`SubscribeEvent`只对应通用初始化日志；其`ProjectionScreen`/`ProjectionScreenResp`命中仍是通用日志、错误和响应路径，没有形成`MMI_DVR_Command`到ProjectionScreen/EVS的数据流。其它服务即使含通用SubscribeEvent错误字符串，也没有与DVR类型相连的独立回调证据。由此关闭“消费者藏在相邻middleware文件”的分支，但不把注册表等同于运行时订阅成功，也不据此断言CP或硬件不存在。

继续定点审查HMI唯一具体符号`ClusterServiceHandler::HandleEventDVRConfig`：它从事件适配器取`unsigned char`样本，逐字节写`LogInfo`，本体只检查取样结果并返回；没有ProjectionScreen、EVS、窗口或媒体调用。因此DVRConfig在该HMI原件中是取样/日志路径，不是画面入口。详情见[处理器报告](raw/cp-b/hmi-dvrconfig-handler-20261017.md)。

`cm_config.json` 还确认部署层确实包含 VehicleService 的 `DVR_SystemSts`/`MMI_DVR_Command` 默认事件组、MixtureService 的 `DVRConfig` 默认事件组，以及 IVI/DFS 的 `ProjectionScreen` 方法和响应事件。这证明 CP 服务描述有 DVR 端点，但不证明订阅、事件到达或 DVR 回调调用投影；当前仍没有 MMI_DVR→ProjectionScreen/EVS 数据流。详情见[部署报告](raw/cp-b/cm-dvr-deployment-20261017.md)。

当前仍缺少：独立模块在线的正证据、D8实际效果与可靠退出恢复、DVR画面/录像/回放的可执行消费者，以及DVR配置枚举的产品含义。后续只在CP槽位/build变化、匹配debug/event binding出现，或运行记录把33033与字段访问联系起来时重查；相同二进制、全零状态、重复常量和通用日志不再作为进展。

对“邪道”旁路的有限核验也完成：车机 `Download` 没有原厂/第三方 DVR、CardVR、Longhorn、RoadRover 或旧 Neusoft DVR 安装包，不能直接启动现成 APK。伪造入口或注入通用事件只能测试 UI，不能证明真实录像；D8 仍缺 payload 语义和模块响应证据，未发送。

详细证据与边界见[本轮报告](raw/cp-b/middleware-dvr-crosscheck-20261017.md)、[交叉引用汇总](raw/cp-b/middleware-dvr-xrefs-20261017.txt)和[代表性反汇编](raw/cp-b/middleware-dvr-xref-contexts-20261017.txt)，以及此前的`RESULT_20261015.md`和`branch_log.md`。

本轮追加的公开资料搜索找到《领克行车记录仪》《领克DVR》手机端说明，以及第三方索引中的 `com.bvc.geely.camera`（Geely GO）Android候选；它们都以Wi‑Fi连接独立记录仪，尚未证明是本车Flyme车机原厂消费者。当前车机无线处于SoftAP（`Sakiko 的领克 06`、2客户端），station未初始化且扫描计数为0，所以空扫描不能证明车内无记录仪。详见[公开材料与Wi‑Fi报告](raw/public-dvr-material-search-20261017.md)。只有取得匹配DVR热点、同配置系统包/模块料号或进入station扫描路径后才重查。

另对 `pm list packages -u -f` 做了已卸载/禁用包名补漏，按现有 DVR/供应商关键词无匹配；没有发现仅因用户卸载或禁用而隐藏的同名 DVR 包。详见[隐藏包补漏报告](raw/hidden-package-dvr-check-20261017.md)。

# 隐藏/已卸载包名补漏（2026-10-17）

## 解决的未知问题

确认原厂 DVR 是否只是被禁用或对当前用户卸载，导致普通 `pm list packages` 看不到。

## 检查与结果

对已连接车机执行只读 `pm list packages -u -f`，按 `dvr`、`cardvr`、`longhorn`、`roadrover`、`neusoft`、`dash`、`行车`、`记录` 筛选；无匹配输出。没有改变包状态，也没有启动或安装候选。

这关闭了“同名包仅被用户卸载/禁用”的窄分支，但不排除厂商把功能打进无明显命名的系统组件，或包根本未随本车配置提供。只有系统版本/包清单变化、取得 donor 包或出现具体组件名时重查。

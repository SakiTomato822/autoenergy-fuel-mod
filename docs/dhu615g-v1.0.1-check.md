检查日期：2026-10-14。车机 Android 11 / API 30，可用内容区域 1920×896，状态栏 72 px、底部系统栏 112 px。

从 GitHub Release 下载 1.0.1（versionCode 25），核对 SHA-256 与发布附件一致，签名证书与车机已有 0.6.7 一致，ADB 覆盖安装成功。覆盖安装保留 DUMP、CAR_ENERGY、CAR_SPEED 授权，启动时未调用 Root 授权流程。

实车截图确认统计页、曲线和浅色主题可显示，发现并修复：

- 浅色主卡片仍使用深色底，导致深色文字对比度不足；主卡片改用浅色表面色。
- 曲线图的单位、分段均值、横纵轴刻度沿用深色模式的浅色文字；浅色模式改为深色文字与蓝色曲线、适度减淡面积填充。
- 统计页仅填充设计画布，等比例适配后两侧露出深色背景；将统计页底色延伸至完整视口，并保留页面切换透明度。

后续实车反馈修正：

- 背景仅在完整视口绘制一次，移除设计画布内的重复底图和重复浅色蒙层，避免边缘接缝及浅色过亮。
- 浅色主题改用柔和灰蓝背景与卡片色，保留深色文字和清晰曲线。
- 主题按钮提供“随系统 → 浅色 → 深色”循环选择并持久化；未选择新模式时默认随系统。旧版二态偏好不再阻止默认系统联动。
- 读取 Android `uiMode` 夜间标记，处理 `uiMode` 配置变化，并在返回页面时重新同步。实车当前报告 `mNightMode=2 (yes)`、`mCurUiMode=0x23`，支持读取标准夜间状态。
- 新增主题状态测试，覆盖系统变化、手动覆盖、三态循环和偏好恢复。

1.0.1 为纯油耗版本，不包含地图或 GPS 轨迹；旧地图 DNS 修复草稿没有合入本次适配。

本次没有实测完整卸载重装后的 JSON 自动找回、文件选择器导入导出、物理开机或长时间后台稳定性。

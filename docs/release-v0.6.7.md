# 0.6.7 — DHU615G 读取修复与后台油耗记录

修复 [issue #1](https://github.com/SakiTomato822/autoenergy-fuel-mod/issues/1)：0.6.6 的 MCU 解析器未识别实车 `Property` 与 `zone` 字段，即使 DUMP 已授予仍丢弃有效数据。现在兼容真实输出和旧格式，保留属性、区域 0、状态 0、字节长度及数值范围校验，并加入实车格式回归测试。

## 数据读取

统一为一轮 MCU 查询，避免合并后重复读取。即使 CarProperty 连接失败，已读到的 MCU 油耗、油量、续航和行程数据仍能显示。平均油耗仅在单位属性为 1 时按十分位转换；本次里程为 0 时不显示无有效分母的本次平均油耗。

| 字段 | MCU 属性 | 字节数 | 换算 |
| --- | --- | --- | --- |
| 本次平均油耗 | `0x28700440` | 2 | / 10 L/100km |
| 小计平均油耗 | `0x28700048` | 2 | / 10 L/100km |
| 油耗单位 | `0x28700026` | 1 | 1 才转换油耗 |
| 剩余油量 | `0x2870043a` | 2 | % |
| 燃油续航 | `0x2870001e` | 4 | km |
| 自动重置方式 | `0x28700022` | 1 | 1 加油、2 停车 |
| 总里程 | `0x2870043b` | 4 | km，待仪表逐项确认 |
| 小计 / 本次里程 | `0x28700020` / `0x2870043c` | 4 | / 10 km |
| 小计 / 本次平均车速 | `0x28700047` / `0x2870043e` | 2 | km/h |
| 小计 / 本次时长 | `0x28700049` / `0x2870043d` | 4 | / 60 分钟，秒单位待仪表确认 |

字节按大端无符号整数解码，支持 dumpsys 打印的负数字节。该路径固定白名单、只读，不写车辆属性。

## 记录与存储

- 新增常驻通知的前台采集服务；页面关闭后继续记录，支持 START_STICKY、开机和覆盖安装广播。
- 每轮读取完成后等待约 5 秒；累计约 3 km 记录区间油耗。估算累计耗油为 `平均油耗 × 本次里程 / 100`，区间油耗为 `耗油差 / 里程差 × 100`。
- 行程重置时重建基线，保留历史；怠速时保留耗油基线，计入下一段。原始平均油耗取整会影响短区间精度。
- `Download/AutoEnergyData/history-*.json` 为本地数据源，保存全部历史与采集进度。新曲线点立即保存，普通进度约每分钟保存。
- 新文件写入、回读校验后发布；保留前一代，启动尝试有效代次。格式版本与 SHA-256 用于识别损坏，不是防篡改认证。
- 自动迁移旧 SharedPreferences 历史；诊断页可立即保存和选择已有 JSON。数据损坏不清零覆盖，实时读数仍可显示。
- 卸载后需手动选择原共享文件并重新授予 DUMP。物理开机、完整卸载重装恢复尚未实测；强行停止后需手动启动。

## 界面与日志

- 主要内容保持等比例缩放，底层背景填充视口，解决左右黑边和横向拉伸。
- 实车重置方式只读，显示停车 / 加油重置，未知时不选中。小计重置仅在模拟器中提供。
- 日志改存应用内部目录，避免该车机外部日志目录 EACCES。

## 安装与验证

版本 `0.6.7`、versionCode `23`。CI Debug 包为 `com.lynk.autoenergyfuel.dhureadonly`，可与旧包并排安装；Release 包名仍为 `com.lynk.autoenergyfuel`。Debug 与旧官方包的签名不同，不能互相覆盖。

```sh
adb install -r app-debug.apk
adb shell pm grant com.lynk.autoenergyfuel.dhureadonly android.permission.DUMP
```

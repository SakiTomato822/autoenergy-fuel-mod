# 0.6.6 — DHU615G 实车读取修复候选版

- 新增 MCU DUMP 只读读取：本次 / 小计平均油耗、油量、续航、自动重置方式。
- 校验属性、区域、状态、字节长度、范围；不猜测里程属性。
- 拒绝未映射适配层返回的未经确认的油耗零值。
- 重置选项不再预先选中或在失败时跳到相反选项。
- 保留原包名、构建签名配置和原 UI；不加入 3D 车模。

安装后需通过已连接车机的 ADB 执行一次：

```sh
adb shell pm grant com.lynk.autoenergyfuel android.permission.DUMP
```

日志出现 `mcu.dump ...` 后，请对照仪表检查油耗、油量、续航。油耗十分位倍率仍需实车对照，里程和曲线尚不保证恢复。不新增车辆写入能力，不保证普通安装即获系统权限。

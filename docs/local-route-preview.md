# 本地行程轨迹（无地图 SDK）

## 本版范围

- 统一冷蓝灰配色；燃油余量增加“约 X.X L”。油箱标称容量 50 L 由车主确认，升数仅为百分比换算，不使用标准 VHAL 的占位容量。
- 里程统计右上角进入行程轨迹页。此页仅绘制定位轨迹，无道路、地名、路况或导航能力。
- Android 系统 LocationManager 提供定位，不依赖 Google Play 服务、地图 Key 或第三方 SDK。实车能否提供有效定位尚待验证。
- 用户同意说明并授予精确定位权限后，启动独立的 location 前台服务；切换到其他 App 后可继续记录，通知和页面均可结束记录。
- 不申请 ACCESS_BACKGROUND_LOCATION，不随开机启动定位，不在进程死亡后自动重新开始录制。
- 定位间隔请求约 5 秒；实际回调受定位源控制。丢弃精度超过 50 m、超过 30 秒的旧定位、重复/过密定位和短时间不合理跳点。超过 30 秒的定位中断断开折线。
- 路线按 GPS speed 着色；速度缺失时灰色，不用车辆平均速度冒充实时速度。
- 点选轨迹可查看定位时间、精度、GPS 速度、最近车辆快照中的本次累计里程和累计平均油耗。超过 15 秒的车辆快照不附加；MCU 多属性仍为串行读取，不构成原子快照。
- 不把累计平均油耗当作该坐标的瞬时油耗。后续可用时间段关联估算油耗段，缺少有效数据的区段应保持未知。

## 数据与隐私

轨迹以 WGS84、带版本头的 JSONL 保存于应用 `noBackupFilesDir/routes/`，不上传、不调用在线底图，并排除 Android 自动备份。已有油耗历史 JSON 的位置不变。

每个定位点独立追加，读取时忽略进程中断遗留的损坏尾行；停止时写入结束标记。异常终止可能没有结束标记，历史仍可查看，不视为正常结束。

页面提供最近 30 个文件的历史选择；预览最多载入最近 10000 点，文件读取上限 20 MiB。较长行程的页面统计仅针对载入部分，不代表完整行程。暂未提供轨迹导出和删除管理。卸载 App 会删除这些私有轨迹，不能误认为它们已包含在共享油耗 JSON 中。

## 下一阶段

先实车验证定位权限、GNSS 是否可用、切导航后台记录及磁盘行为，再选底图。国内底图需要正确处理 WGS84 与供应商坐标系，不能直接将原始 GPS 坐标贴到高德而忽略偏移。

模拟器的“演示轨迹”是明确标记的合成数据，不写入行程文件，不证明实车定位能力。

当前 API 30 模拟器的原生 GNSS 曾输出与开机单调时钟不一致的 elapsedRealtimeNanos，正常校验会拒绝。另提供仅打入 androidTest APK 的 RouteSmokeInstrumentation：禁止在真实车辆上运行，使用测试定位源和正确的单调时间验证本地持久化。不会为适应模拟器异常而放宽正式记录器校验。

已在 API 30 模拟器验证：受控定位 3 点落盘、切到桌面后继续记录、主动结束写入标记，以及重新打开页面读取已保存轨迹并点选查看 GPS 速度。实车定位和长时间运行尚未验证。
